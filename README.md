# ThinkBerry
A project to solve my niche problem of accessing my online textbooks!

Why this project?

This project began mainly because my desk is too small! 
Currently, when I need to access my online textbooks I have to open them on my laptop, which takes up all of my desk space, meaning that  then have to place my notebooks on top of my keyboard to write and answer the questions. This meant that as I was writing, my keyboard would be clicked, without me intending too. Resulting in the textbook skipping to a different page or even closing entirely. 

So as a solution to this niche problem, I began experimenting with the idea of having a small foot print raspberry pi based computer to display my questions, freeing up my desk space for me to write and eliminating the potential distractions which are present when having a laptop in front of me. 

This is when the ThinkBerry was born!
